# FCC ZIP tables for yourbillcheck.com
Monthly GitHub Action downloads FCC BDC availability per state and writes `zipdata/out/<st>-zips.json`.
Secrets needed: FCC_USERNAME (your FCC BDC login email) and FCC_TOKEN (API token from bdc.fcc.gov > Manage API Access).
Run manually: Actions > "Build FCC ZIP availability tables" > Run workflow (states like "TX:48 FL:12 GA:13").
